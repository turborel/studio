# Keyboard Shortcuts

[Contents](README.md)

Each of Studio's commands, its menu, and its key by default, on macOS and
on Linux and Windows. **File > Settings… > Keys** binds a command to
another key, or to none ([The Window](../user/02-window.md#keys)); the
command palette and **Help > Keyboard Shortcuts** show the keys as they
are bound.

Within a dialog, Tab and Shift+Tab move between its fields, and Escape
closes it, and Studio's keys wait until it is closed. In the command
palette, the arrow keys choose a command and Enter runs it. The Edit
menu's keys are the platform's own.

In a worksheet's editor, Studio's keys come first: a key bound to one of
Studio's commands runs it, wherever the cursor is. The editor's own keys
are the rest: Tab, in a snippet, moves to its next field; Ctrl+Space
asks for completion; Cmd+Z, or Ctrl+Z, undoes; Alt+Up and Alt+Down move
a line; a click with Cmd, or Ctrl, adds a cursor; Cmd+Alt+[, or
Ctrl+Shift+[, folds a statement, and the same with ] unfolds it.
