# Keyboard Shortcuts

[Contents](README.md)

Each of Studio's commands, its menu, and its key by default, on macOS and
on Linux and Windows. **File > Settings… > Keys** binds a command to
another key, or to none ([The Window](../user/02-window.md#keys)); the
command palette and **Help > Keyboard Shortcuts** show the keys as they
are bound.

| Command | Menu | macOS | Linux, Windows |
|---|---|---|---|
| New Connection… | File | Cmd+Shift+N | Ctrl+Shift+N |
| Disconnect | Connection | | |
| Reconnect | Connection | | |
| Cancel Statement | Connection | Cmd+. | Ctrl+. |
| Commit | Connection | | |
| Rollback | Connection | | |
| Command Palette… | View | Cmd+Shift+P | Ctrl+Shift+P |
| Settings… | File | Cmd+, | Ctrl+, |
| Theme: System | View | | |
| Theme: Light | View | | |
| Theme: Dark | View | | |
| Zoom In | View | Cmd+= | Ctrl+= |
| Zoom Out | View | Cmd+- | Ctrl+- |
| Actual Size | View | Cmd+0 | Ctrl+0 |
| Reset Layout | View | | |
| About Turborel Studio | Help | | |
| Keyboard Shortcuts | Help | F1 | F1 |

Within a dialog, Tab and Shift+Tab move between its fields, and Escape
closes it. In the command palette, the arrow keys choose a command and
Enter runs it. The Edit menu's keys are the platform's own.
