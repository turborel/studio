# Versions

[Contents](README.md)

Turborel Studio's version is the number of the Turborel release it is
made for, the same as the server's ([VERSIONING.md](../../VERSIONING.md)).
The alpha is 0.0.0, made for Turborel 0.0.0, and nothing about it is
promised: its behaviour and its files may change in any build.

| Studio | Turborel | Protocol |
|---|---|---|
| 0.0.0 (alpha) | 0.0.0 (alpha) | 1 |

Studio reaches a server through turborel-client, Turborel's own client
library, built from one commit of Turborel's main.
